# Product

## Register

product

## Users

ArgusOS is for its developer, operating-system students, and retro-computing
enthusiasts using a physical desktop or a QEMU window. They need to inspect the
machine, run kernel commands, and understand which parts of the system are real.

## Product Purpose

ArgusOS is a small, legible x86-64 study operating system that grows one honest
subsystem at a time. Success means the interface makes low-level state easier to
see and control without disguising the kernel's current limitations.

## Brand Personality

Restrained, technical, and professional. The interface should have the durable,
direct quality of a well-maintained Unix workstation without turning its period
influences into product naming or decorative nostalgia.

## Anti-references

Do not make ArgusOS a glossy Windows XP clone, a literal imageboard clone, a neon
cyberpunk terminal, a glassmorphic dashboard, or a collection of rounded cards.
Do not use era labels, copied artwork, fake system state, or nonfunctional chrome.

## Design Principles

1. Show real system state and label prototypes honestly.
2. Prefer keyboard-first utility over decorative interaction.
3. Make the handmade constraints feel intentional.
4. Keep the interface calm enough for long technical sessions.
5. Use interface text only when it names an action, surface, or real state.

## Accessibility & Inclusion

Maintain readable contrast even within the muted palette, never communicate
state through color alone, preserve serial access, and limit motion to necessary
state changes. Controls must remain usable from the keyboard as mouse support is
introduced.
